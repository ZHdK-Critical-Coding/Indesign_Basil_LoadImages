Installation Notes
==================

The following simlinks are necessary:

CHECK: https://basiljs2.netlify.app/tutorials/01-getting-started/

- If you don't install basil into ~/Documents/basiljs add a simlink there:
  `ln -s /Path/to/source/basiljs ~/Documents`
- Otherwise adapt the // @includepath "~/Documents/;%USERPROFILE%Documents"; directive
- Simlink scripts into the scripts folder of indesign:
  `ln -s "/Path/to/source/Basil Scripts" /Applications/

remove b. from examples if they fail.
